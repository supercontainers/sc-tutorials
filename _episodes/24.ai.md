# Agentic AI

The following hands-on exercise makes use of these repositories:
- [ADK Currency Agent](https://github.com/srbdev/adk_currency_agent)
- [Currency Client](https://github.com/srbdev/currency_client)
- [Currency MCP](https://github.com/srbdev/currency_mcp)

_Note that these examples are derived from the A2A Project samples' [repository](https://github.com/a2aproject/a2a-samples/tree/main/samples/python/agents/adk_currency_agent)._

## Openrouter

1. Sign up for an OpenRouter account [here](https://openrouter.ai)
2. New users receive a small free allowance
3. Set a new API key that'll expire in an hour or a day and with a custom credit limit of $0.
4. Pick one of the free models listed [here](https://openrouter.ai/models?variant=free), e.g. `nvidia/nemotron-3-ultra-550b-a55b:free`.

## Currency Agent

```bash
git clone https://github.com/srbdev/adk_currency_agent.git
cd adk_currency_agent
cp .env.example .env
vim .env
```

1. Update `OPENAI_API_BASE` with `https://openrouter.ai/api/v1`
2. Update `OPENAI_API_KEY` with your key
3. Update `OPENROUTER_MODEL` with your model ID

```bash
uv sync
uv run currency_agent
```

## Client

```bash
git clone https://github.com/srbdev/currency_client.git
cd currency_client
uv venv
source .venv/bin/activate
uv pip install -r requirements.txt

uv run python cli.py --url http://localhost:10999
```

Enter a user prompt to make sure that the backend agent is correctly bootstrap with the LLM.

## Kubernetes

_Note that the following only show basic capability of running agents on Kubernetes and is not meant for production._

1. Update [`deployment.yaml`](https://github.com/srbdev/adk_currency_agent/blob/main/deployment.yaml) in `adk_currency_agent` with env variables (as done in previous steps)
2. Deploy agent

```bash
kubectl create namespace NAME
kubectl apply -f deployment.yaml -n NAME

kubectl port-forward svc/currency-agent-service 10999:10999 -n NAME
```

3. Restart client

## MCP

```bash
git clone https://github.com/srbdev/currency_mcp.git
cd currency_mcp
kubectl apply -f deployment.yaml -n NAME
```

### Update Agent

```bash
git checkout with-remote-mcp

# If `git` complains about overwritting changes in `deployment.yaml`
git stash
git checkout with-remote-mcp
git stash pop
# make sure no conflicts in `deployment.yaml`
```

1. Update `MCP_SERVER_HTTP_URL` in `deployment.yaml` with Service IP address from MCP server, using the format `http://IP:8080/mcp`

```bash
kubectl get services -n NAME
# and copy `CLUSTER-IP` for `currency-mcp-service` row

kubectl delete deployments/currency-agent -n NAME
kubectl apply -f deployment.yaml -n NAME
kubectl port-forward svc/currency-agent-service 10999:10999 -n NAME
```

2. Restart client

## Bonus

### Ollama

1. Verify if a model is available for your node: `ollama ls`
2. _If not already downloaded, run `ollama pull nemotron-3-nano:4b` to download it locally_
3. Run `ollama run nemotron-3-nano:4b` for a basic chat interaction with the model

### Pi

The Pi harness is already available for you but needs to be configured to talk to the large-language model (LLM) hosted locally by Ollama.
Create the file `~/.pi/agent/models.json` with content:

```json
{
  "providers": {
    "ollama": {
      "baseUrl": "http://localhost:11434/v1",
      "api": "openai-completions",
      "apiKey": "ollama",
      "models": [
        {
          "id": "nemotron-3-nano:4b"
        }
      ]
    }
  }
}
```

Then run `pi` to start the harness.

To use your OpenRouter key with the Pi harness, simply run `export OPENROUTER_API_KEY=sk-or-v1-xxx` before running `pi`.
Make sure to pick the same free model from earlier, using the Pi `/model` command.
